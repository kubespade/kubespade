What is KubeSpade?

KubeSpade is a Kubernetes GUI and desktop/iPad kubectl alternative for engineers who manage clusters every day. Use it as a Kubernetes client for Amazon EKS, Google GKE, Azure AKS, minikube, or any cluster you reach with a kubeconfig — without sending credentials through a third-party cloud console.

Your credentials never leave your device

KubeSpade stores kubeconfig and cloud credentials locally. We don't operate a backend that receives your cluster secrets or API traffic.

  • Direct connection to Kubernetes API
  • Keychain / secure storage on each platform
  • Privacy Policy · Terms of Use

Works with the clusters you already run

Whether you manage EKS in production or spin up minikube locally — same UI, same workflows.

  • AWS EKS, GCP GKE, Azure AKS
  • Any cluster reachable via kubeconfig
  • Exec plugins (e.g. aws-vault) supported on desktop
