What to install when OpenLens is no longer maintained

OpenLens was the escape hatch when Lens Desktop started requiring an account. For many teams it stopped being a safe default: stale builds, no clear maintainer, and the same Lens-era UX debt. KubeSpade is a separate Kubernetes GUI — not a fork — built for day-to-day cluster work without a vendor login.

If you landed here from a search for openlens alternative or openlens dead, you are not alone. OpenLens filled a real gap for years. In 2026 the practical question is not “where do I download OpenLens again?” but “what do I install that still gets updates and does not route my kubeconfig through another account?”

KubeSpade is an independent Kubernetes client for macOS (Apple Silicon and Intel), Windows (x64 and ARM), and Linux (.deb and AppImage). Connect with kubeconfig, Amazon EKS, Google GKE, or Azure AKS. Credentials stay on your device. There is no KubeSpade cloud that receives your tokens.

Other paths people take

  • FreeLens — another Lens fork, MIT-licensed. Closest to “install OpenLens again” if you want the same UI family.
  • Lens Desktop — still updated by Mirantis; requires a Lens account for the current product.
  • Headlamp — CNCF web UI; great if a browser-based dashboard is enough.
  • k9s — terminal UI; no mouse-first workflow.

KubeSpade is not trying to win on “most Lens-compatible.” It is for engineers who want a desktop GUI that ships updates, stays off a vendor account, and will run on iPad too.

When OpenLens is still fine

  • Your build runs on your OS and Kubernetes version today.
  • You are not planning cluster upgrades soon.
  • You accept that security fixes and new K8s APIs may never arrive.

That is a valid short-term choice. It is not a 2026 migration plan.

When people leave OpenLens

  • The app fails on a new macOS or Windows release.
  • Kubernetes upgraded and the old client misbehaves.
  • They want something maintained without signing into Lens.
  • They want the same workflows on iPad.
Is KubeSpade a drop-in OpenLens replacement?

For browsing clusters, logs, YAML, exec, and Helm — yes, that is the daily job. It is not a drop-in for Lens extensions or an identical Lens layout. Expect a different UI, not a re-skinned fork.

Should I try FreeLens first?

If your main goal is “the same Lens UX without Mirantis,” FreeLens is the honest first stop. Try KubeSpade if you want an independent codebase, no Lens lineage, or iPad support.

Do I need kubectl installed?

Not for clusters you connect in the app. The desktop client talks to the Kubernetes API itself. You can still use kubectl alongside it for scripts.

Is there a free download?

Yes. Desktop builds are on the Download page (GitHub Releases, with SHA256SUMS). Verify the checksum before you install.
