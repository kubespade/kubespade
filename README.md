# KubeSpade

**KubeSpade** is a Kubernetes GUI client for **macOS**, **Windows**, **Linux**, and **iPad**.

Browse workloads, stream logs, edit YAML, exec, port-forward, Helm, Desktop AI, and more — day-to-day cluster work without living in the terminal. Credentials stay on your device.

Website: [https://www.kubespade.com](https://www.kubespade.com)

---

## What this repository is

This is the **public releases & support** repo.

| Here | Not here |
|------|----------|
| [GitHub Releases](https://github.com/kubespade/kubespade/releases) — Desktop installers (`.dmg`, `.exe`, `.deb`, AppImage) and checksums | Application source code |
| [Issues](https://github.com/kubespade/kubespade/issues) — bugs and feature requests | The marketing site (hosted separately) |
| Links to download and docs | Private app repositories |

Desktop builds are attached to **Release** tags (for example `v1.3.0`). Prefer the [Download](https://www.kubespade.com/download.html) page or the latest Release — verify with `SHA256SUMS.txt` when provided.

## Download

- **Desktop:** [kubespade.com/download](https://www.kubespade.com/download.html) or [Releases](https://github.com/kubespade/kubespade/releases)
